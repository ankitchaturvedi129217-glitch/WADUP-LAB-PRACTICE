# PHP Lab Practicals (WADUP)

A collection of PHP laboratory practicals developed as part of the Web Application Development Using PHP (WADUP) course. This repository contains basic to intermediate PHP programs that demonstrate core web development concepts such as forms, sessions, cookies, file handling, and more.

## 🚀 How to Run

### Using XAMPP

1. Install XAMPP.
2. Copy the project folder into:

```
htdocs/
```

3. Start **Apache** from the XAMPP Control Panel.

4. Open your browser and visit:

```
http://localhost/WADUP-LAB/
```

---

### Using Laragon

1. Install Laragon.
2. Copy the project folder into:

```
www/
```

3. Start Laragon.

4. Open:

```
http://localhost/WADUP-LAB/
```
